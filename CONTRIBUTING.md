# Contributing

Use one focused feature branch per change and open a pull request. Read `AGENTS.md` and the
applicable architecture, security and testing documents first. Keep provider/game boundaries
unchanged and include exact commands, commits, evidence labels and limitations in the pull request.

Do not commit credentials, private captures, personal paths, proprietary game files or copied
implementation source. Maintainers merge, release and deploy; contributors and agents prepare and
verify changes.
