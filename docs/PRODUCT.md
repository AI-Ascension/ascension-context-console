# Product contract

The console answers which application-controlled components were prepared for a decision, how the
selected adapter represented or omitted upstream fields, which bytes/measurements are available,
and which decision/action lineage is linked. It is an inspection tool.

It does not expose provider-internal instructions or reasoning, edit/apply/compact/retrieve
context, pause/resume a run, submit prompts, retry actions, or manipulate game state. Comparisons
are local read operations and never preview or alter a future provider input.
