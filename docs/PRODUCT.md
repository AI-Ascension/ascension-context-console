# Product contract

The console answers which application-controlled components were prepared for a decision, how the
selected adapter represented or omitted upstream fields, which bytes/measurements are available,
and which decision/action lineage is linked. Phase 2 also lets an authorized operator create a
bounded draft, review the exact prepared material, hold the scheduler at a validated boundary,
commit a revision, and resume explicitly.

It does not expose provider-internal instructions or reasoning, compact or retrieve context, submit
prompts, retry actions, or manipulate game state. Notes are attributed model-visible data and never
host authority. A commit changes only the future prepared context revision; it does not start
inference or automatically resume a run. Comparisons remain local read operations.
